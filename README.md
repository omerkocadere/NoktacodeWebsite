# Noktacode — Yazılım Çözümleri

Modern, koyu temalı, iki dilli (TR/EN) yazılım firması web sitesi.

## Teknolojiler

- **HTML5** — Semantik yapı
- **Tailwind CSS** (CDN) — Utility-first CSS framework
- **Vanilla JavaScript** — Sıfır bağımlılık
- **Lucide Icons** — Modern ikon seti
- **Google Fonts** — Inter font ailesi

## Özellikler

- Glassmorphism tasarım kartları
- TR/EN dil değiştirme (localStorage ile kalıcı)
- Scroll animasyonları (Intersection Observer)
- Sayaç animasyonları (count-up)
- Mobil responsive tasarım
- İletişim formu
- Floating particle animasyonları
- Navbar scroll efekti

## Bölümler

1. **Hero** — Gradient animasyonlu giriş bölümü
2. **Hizmetler** — 6 adet hizmet kartı
3. **Hakkımızda** — Firma tanıtımı ve istatistikler
4. **Projeler** — 6 adet proje kartı
5. **İletişim** — Form ve iletişim bilgileri
6. **Footer** — Hızlı linkler ve sosyal medya
